वीडियो जनरेशन अनुरोध

API प्रदाता या अपने सर्वर पर चलने वाला स्थानीय मॉडल चुनें। स्थानीय मॉडल के लिए GPU/पर्याप्त RAM और मॉडल वज़न चाहिए; पहली बार मॉडल डाउनलोड करना पड़ सकता है।

Direct Model मोड में मॉडल backend मशीन पर चलेगा। यह ब्राउज़र में डाउनलोड या रन नहीं होगा।

यह पता केवल इसी ब्राउज़र में रखा जाएगा। API key यहाँ न डालें। API key backend के environment secrets में रखनी होगी।

कार्य की स्थिति

अभी कोई जनरेशन कार्य नहीं है।

तैयार वीडियो खोलें

सुरक्षा और लागत

  • Provider API key को HTML, JavaScript, GitHub या localStorage में नहीं रखना है।
  • Backend को provider की key server-side environment secret से पढ़नी चाहिए।
  • Direct Model के लिए backend पर PyTorch, Diffusers, वीडियो encoder और पर्याप्त GPU/RAM की ज़रूरत हो सकती है।
  • स्थानीय मॉडल और API मोड backend पर अलग-अलग सक्षम करने होंगे।
  • मॉडल/API की कीमत, मुफ़्त सीमा और उपयोग-अधिकार जाँचने के बाद ही असली अनुरोध चालू करें।
  • वीडियो फाइल को GitHub repository में स्टोर न करें; media storage अलग रखें।
